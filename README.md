# Goseong, by the sea

2026년 11월 4일-6일 강원 고성 2박 3일 여행을 위한 인터랙티브 스토리맵입니다. `paju-weekend-2026`과 같은 구조(정적 HTML + Leaflet 지도)로 만들었습니다.

서울에서 10시 자차 출발을 기준으로, 첫날은 남쪽(토성면)에서 점심을 먹고 가진의 카페를 거쳐 북쪽 숙소(라헨느 풀빌라 J동)로 올라갑니다. 둘째 날만 교암으로 나들이하고, 마지막 날은 내려오는 길에 가리비(A안) 또는 카츠산도(B안) 한 끼로 마무리합니다.

## 주요 기능

- 1일차부터 3일차까지 날짜별 이동 경로 지도
- 마지막 날은 A안(백도수산 가리비)과 B안(보배진 카츠산도)을 지도에서 전환
- 장소 선택에 맞춘 지도 포커스와 시간대 배경 변화
- 차량 마커가 경로를 따라 움직이는 일정 재생
- 장소별 공개 사진, 후기 요약, 원문과 지도 링크
- 출발 전 전화 확인 목록(입실·바비큐 조건, 서점 영업 공지, 가리비 재고, 카츠산도 판매 여부)
- 바람·도착 지연에 대응하는 대체 일정
- 시스템 색상 모드와 수동 테마 전환, 모바일 반응형, 모션 감소 설정 지원

## 로컬 실행

별도 빌드 과정이 없는 정적 페이지입니다.

```bash
python3 -m http.server 4174
```

브라우저에서 `http://localhost:4174`를 엽니다.
